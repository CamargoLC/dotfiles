
# dotfiles
Welcome at my Void.

## 💻 Configuração
* **Window Manager:** bspwm
* **Terminal:** st
* **Shell:** zsh + oh-my-posh (shell prompt para o terminal)
* **Editor:** neovim
* **Launcher / Powermenu:** rofi
* **Compositor:** picom
* **Teclas de atalho:** sxhkd
* **Wallpaper Manager:** feh e nitrogen
* **Informações do Sistema:** fastfetch + btop

> "Enter into the Void."
